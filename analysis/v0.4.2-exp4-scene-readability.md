# v0.4.2-exp4-scene-readability

## Request

Improve `exp4_local_scene_3d.png` and `exp4_global_scene_3d.png` because some points and camera markers overlap and are hard to distinguish.

## Changes

- Removed per-camera text labels from the Experiment 4 scene figures.
- Kept the scene geometry unchanged, but changed the rendering style:
  - landmarks are more transparent,
  - fixed reference views are shown as open black circles,
  - optimized later views are shown as purple diamonds,
  - the camera path is slightly emphasized.
- Adjusted the viewing angle to separate the camera path from the point cloud more clearly.
- Regenerated:
  - `outputs_exp4/exp4_local_scene_3d.png`
  - `outputs_exp4/exp4_global_scene_3d.png`
- Updated `README.md` so the Experiment 4 scene descriptions explicitly explain the new marker meanings.

## Notes

- No optimization code or numerical Experiment 4 results changed in this version.
- This is a visualization-readability update only.
